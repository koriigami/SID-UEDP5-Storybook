## Accessibility

- `<label>` is always rendered and associated with the input via `htmlFor`.
  Use `hideLabel` when the label would be visually redundant — it stays in
  the accessibility tree.
- Errors set `aria-invalid="true"` and are announced through
  `aria-describedby` + `role="alert"`.
- Focus ring is a token-driven double outline that meets WCAG 2.4.11
  ("Focus Not Obscured (Minimum)") on hover-adjacent controls.
