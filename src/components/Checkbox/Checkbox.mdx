## Accessibility

- Backed by a real `<input type="checkbox">`. Native keyboard + screen-reader
  behaviour, no custom `role="checkbox"` shim.
- Indeterminate state exposes `aria-checked="mixed"`.
- Error state sets `aria-invalid="true"` so assistive tech can announce the
  invalid checkbox even when the label doesn't say "error".
