## Accessibility

- `focus-visible` shows a ring built from `--color-focus-ring` +
  `--size-focus-ring`; hitting <kbd>Tab</kbd> in the canvas will trigger it.
- Loading buttons set `aria-busy="true"` and disable pointer interaction so
  assistive tech is not misled.
- `iconOnly` requires `ariaLabel` at compile time (TypeScript union).
- WCAG AA contrast is validated by `@storybook/addon-a11y` on every story —
  see the **Accessibility** tab.

## Motion

Transitions use `--motion-duration-fast` and `--motion-easing-standard`.
Users with `prefers-reduced-motion: reduce` get no transitions and a slower
spinner.
