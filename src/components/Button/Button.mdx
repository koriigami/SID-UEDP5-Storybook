# Button

Mirror of Figma node `14:21` — the Qwark web Button. Variant properties
(`type`, `size`, `state`) map 1:1 to the Figma component, so a change in
Figma should be a token or prop change in code, never a rewrite.

## Accessibility

- Native `<button>` — full keyboard + assistive-tech support out of the box.
- `:focus-visible` shows the double-ring `--color-focus-ring` outline; the
  `forcedState="focused"` prop reproduces it for docs screenshots.
- Loading state sets `aria-busy="true"` and disables clicks, so screen
  readers announce the busy state instead of reading a phantom label.
- `prefers-reduced-motion: reduce` drops the state-layer + focus transitions
  and slows the spinner to 2 s.
